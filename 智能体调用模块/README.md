# 独立预问诊智能体调用模块

本目录是我们负责的独立交付物，**不导入、不修改张科的后端工程**。张科工程只作为接口与流程设计参考。本服务负责逐轮采集症状信息、调用 DeepSeek 抽取自由文本、按后端状态选择一个追问，并生成用户自述摘要。它不使用校医院数据，不提供疾病确诊、处方或个体化用药建议。

## 运行

要求 Python 3.10+，不需要第三方 Python 包。没有密钥时自动运行离线模板模式：

```powershell
cd 智能体调用模块
python server.py
```

接入 DeepSeek：

```powershell
$env:DEEPSEEK_API_KEY = '<服务端密钥>'
$env:DEEPSEEK_BASE_URL = 'https://api.deepseek.com'
$env:DEEPSEEK_MODEL = 'deepseek-flash'
python server.py
```

密钥只由服务进程读取，不能发给前端或提交到仓库。模型名请以正式联调时 DeepSeek 官方可用模型列表为准。本地没有真实密钥，尚未做真实接口联调。

## 独立 HTTP 契约

服务默认只监听 `127.0.0.1:8010`。张科后端可作为调用方访问它，也可由前端在开发环境独立访问；正式部署时建议由张科后端代理该服务，并统一完成鉴权。

1. `POST /v1/sessions`，请求 `{}`，返回 `session_id`。
2. `POST /v1/sessions/{session_id}/turns`，请求 `{"text":"头痛两天了"}`，返回 `action=ask|result|interrupt`。
3. `GET /v1/sessions/{session_id}`，返回当前状态和已收集摘要。
4. `GET /health`，返回服务状态及模型是否配置。

`ask` 响应包含 `question.slot`、`question.text` 和进度。`result` 包含结构化症状摘要。`interrupt` 包含演示规则触发原因和停止追问提示。调用方只需依据 `action` 渲染界面，不应重新解释模型文本。

## 当前安全边界

- 用户原话先经过独立风险词检查；命中演示高危规则时跳过模型调用，直接停止追问。当前规则集只是技术原型，必须经医学组审核、扩充与测试后才可用于真实场景。
- DeepSeek 只抽取允许的字段，并提供逐字原文证据；无效结果丢弃。后端决定下一字段，模型只能改写已选问题，失败则使用固定题面。
- “不知道”记为未知，不当作否认；达到 9 轮上限后用已有信息生成摘要，缺失项写“未采集”。
- 模型失败自动回退模板模式。服务不持久化会话，重启后会话消失；当前仅监听本机，没有用户鉴权，属于开发原型。
- 当前输出是就诊前信息摘要，不给科室推荐。科室引导需要后续经医学审核的规则或知识后再接入。
